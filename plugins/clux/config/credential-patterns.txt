# Credential prompt patterns for the clux companion terminal.
#
# The rule has TWO parts and both must pass. This file is only the second one:
#
#   1. The trimmed line must end in : ? or ]. Every pattern below is
#      unanchored, so this suffix gate is what keeps `token: null` and
#      `Authenticated successfully` out. A pattern that cannot end that way —
#      say `enter your PIN>` — can never match, wherever you put it.
#   2. One include pattern below must match, and no exclude pattern may.
#      Exclusions win over inclusions, in this file or in a user file.
#
# @clux-terminal-patterns may name a second file in this same format. Its
# patterns are added to these; they do not replace them.
#
# Include patterns. Each active line is an extended regular expression,
# matched case-insensitively.
passw(or)?d
pass ?phrase
passcode
\bpin\b
\botp\b
one-time
verification code
2fa
mfa
\btoken\b
secret
private key
enter .*key
sudo\]
authenticat(e|ion)[^a-z]*$
security code
api key
access key
credential
yubikey
touch id
enter .*code

# Exclusions. A leading ! marks an exclusion and is not part of the regex.
!\[y/N\]:?$
!\[Y/n\]:?$
!\[y/n\]$
!\(y/n\)\??$
!\(yes/no\)\??$
