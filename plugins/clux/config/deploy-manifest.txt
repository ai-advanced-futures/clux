# clux deploy manifest — one script per line.

# The single list of scripts /clux:setup copies from the plugin's scripts/
# directory into ~/.config/clux/scripts/. /clux:setup, /clux:validate and the
# bats tests all read THIS file. None of them carries a list of its own.
#
# Why: two hand-written lists already drifted once. CHANGELOG 3.0.9 records
# path.sh sitting in one list and not the other, which shipped installs with a
# missing library.
#
# Readers must skip blank lines and lines whose first non-blank character is #:
#
#   grep -v '^[[:space:]]*#' deploy-manifest.txt | grep -v '^[[:space:]]*$'
#
# Left out on purpose: render-clux-conf.sh and verify-tmux-conf.sh run at SETUP
# time only, from the plugin tree. No key binding, hook or status line ever
# calls them, so deploying them would only put a dead copy on disk.
