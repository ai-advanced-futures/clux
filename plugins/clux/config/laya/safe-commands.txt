# The safe list of the Laya command gate (spec section 7).
#
# A command skips Laya only when its first words equal one full line of this
# file, word for word, no word after them starts with --, and it is one
# simple command with none of these: ; | & < > $ ` ( ) and a newline. The
# safe list applies only to run. The pane shell does not expand aliases, and
# it refuses a safe-list run when the first word is not the program or the
# builtin that terminal.sh found. git is not on the list: the config of a
# repository can start a program (core.fsmonitor, core.pager).
#
# There is no user copy of this file. Claude does not edit it.
ls
pwd
cat
head
tail
wc
echo
