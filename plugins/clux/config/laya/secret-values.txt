# Secret values for the Laya output guard (spec section 8, step 8).
# Python re syntax. Each output line that matches one pattern is held,
# whatever Laya answers. not-secret.txt never removes these holds.
#
# There is no user copy of this file. Claude does not edit it.
# The BEGIN line of a private key is not here: PEM_KEY_BEGIN of
# laya_client.py is the one pattern for it, and value_lines adds it.
AKIA[0-9A-Z]{16}
ASIA[0-9A-Z]{16}
gh[pousr]_[A-Za-z0-9]{36}
github_pat_[A-Za-z0-9_]{22,}
xox[abpr]-[A-Za-z0-9-]+
# No letter or digit before sk-: task-, flask-, disk- and risk- are names.
(?<![A-Za-z0-9])sk-[A-Za-z0-9_-]{20,}
# Stripe secret and restricted keys: an underscore, so sk- does not match.
(?<![A-Za-z0-9])[rs]k_(live|test)_[A-Za-z0-9]{20,}
glpat-[A-Za-z0-9_-]{20}
